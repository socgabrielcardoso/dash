# Fechamento de caso

Antes de marcar um caso como resolvido, deve ficar claro:

- o que aconteceu;
- quais evidências sustentam a conclusão;
- qual foi o impacto;
- o que foi feito;
- se ainda existe risco;
- por que o caso pode ser encerrado;
- se ficou alguma ação pendente.

Um status sozinho não explica uma investigação. O fechamento precisa permitir que outra pessoa entenda a decisão sem refazer todo o caso.
